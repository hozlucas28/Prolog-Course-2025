## Summary

This is a repository where I store all lessons that I take on the programming paradigms assignment of [National University of Matanza](https://www.unlam.edu.ar/) (UNLaM), related with Prolog language.

## Installation

1. Clone this repository.
2. Install [Prolog](https://www.swi-prolog.org/download/stable), and check "Add swipl to the system PATH" option during the installation.
3. Install [Visual Studio Code](https://code.visualstudio.com/), and it's [Prolog extension](https://marketplace.visualstudio.com/items?itemName=rebornix.prolog).
4. That's it! If you want to run the code, open a terminal in Visual Studio Code and type `swipl` to start the Prolog interpreter. Then, load the desired file with the command `consult('file_name').` and start querying.

> [!TIP]
> If you want to execute Prolog code without installing it in your machine, try it's [official playground](https://swish.swi-prolog.org/).
